# 安卓端

原生 Android 8.0+，仅通过 Wi-Fi 与 EtherTransfer 电脑端互传。

- `build.ps1`：使用现有 JDK、Android SDK 编译并开发签名 APK。
- `test.ps1`：Java 协议自检 + 全部 .NET 测试 + Java/C# TCP 互通测试。
- 构建依赖路径在脚本顶部定义。
- 手机接收目录使用系统文件夹授权；传输时保持前台。
- 协议及完整说明见 `../docs/WIFI-ANDROID.md`。


## 0.2.0 界面

蓝白卡片布局：附近设备、待发送文件、接收目录、传输动态；底部固定发送按钮。点击本机名称修改名称。

“清空选择”只清空待发送列表，不删除原文件。未选文件或正在传输时禁用。最多展示前三个文件名，并显示总数。

连接安卓手机后可以运行 `ui-test.ps1` 执行真实 Activity 的状态断言：添加选择、清空、传输时禁用、保留原文件。手机需允许安装独立的 UI 测试 APK。


## 0.3.0 文件夹选择

新增“添加文件夹”，使用系统目录授权后递归发送子目录内容，兼容已有电脑端。文件与文件夹可混合、多次添加，清空时一起移除。整个空根文件夹可发送，内部空子目录没有旧协议记录，暂不保留。
