# 已构建安装包

本目录存放可直接运行的成品，源码在仓库其余目录。

| 文件 | 版本 | 适用 |
| :--- | :--- | :--- |
| `windows-x64/EtherTransfer-0.7.0-win-x64.exe` | 0.7.0 | Windows 10 / 11 x64，双击即用，单文件自包含（含 .NET 运行时），无需安装 |
| `android/EtherTransfer-1.0.0-android.apk` | 1.0.0 (16) | Android 8.0 及以上，需允许"安装未知来源应用" |

**使用要点**

1. 两台设备连同一个 Wi-Fi，或用一根网线直连两台电脑；Windows 首次运行要允许防火墙"专用网络"。
2. 两端都打开软件，左侧"已发现的设备"会自动列出对端，名字旁的小圆点是状态灯：绿=现在能传，红=现在传不过去，灰=还没测。
3. 传文件：添加文件/文件夹 → 选中对端 → 发送 → 对端确认接收。
4. 安卓端建议开启"后台常驻"并关闭电池优化，否则锁屏后可能收不到传输请求。
5. 安卓接收的文件默认在 `内部存储/Download/EtherTransfer/EtherTransfer-时间戳/`。

详细说明见仓库根目录 [README.md](../README.md) 与 [使用说明.md](../使用说明.md)。

> Windows 版为未签名的自编译程序，SmartScreen 可能提示"未知发布者"，选择"更多信息 → 仍要运行"即可。
